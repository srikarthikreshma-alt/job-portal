CareerNest Job Portal Demo

Files:
- index.html: webpage structure
- style.css: responsive styling
- script.js: job data, search, filters, sorting, save buttons, and demo application form

How to run:
1. Extract the ZIP file.
2. Open index.html in a modern web browser.
3. Search jobs, use filters, save a job, or try the Apply now form.

Note: This is a front-end demo. Applications are not sent to employers and no personal data is stored.
